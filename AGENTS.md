# TraceForge engineering instructions

- Preserve original evidence; do not invent telemetry, correlations, or benchmark results.
- Keep all workload generation local and payments fictional.
- Never commit credentials, runtime databases, or private evidence.
- Run backend tests, frontend type checks, and available integration checks after changes.
- Record verification limits honestly in PLAN.md and TESTING.md.
- Explicitly distinguish observed facts, hypotheses, and recommendations.
